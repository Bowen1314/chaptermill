# HPR4743: wl-copy

This episode explains how to use the wl-copy command on a Wayland Linux desktop to copy text and data from the terminal to the system clipboard without using a mouse. It covers installation, basic usage with strings and command output, copying file contents, and alternatives like xclip for X11 systems. Listeners who work in terminals and want efficient copy-paste workflows will find this useful.
